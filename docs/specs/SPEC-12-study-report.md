## Problem

Each trial produces its own report. The roadmap's final deliverable is one study report that draws on all of them, with honest sample sizes and limitations.

## Scope

- **In:** a report in `docs/experiments/study-report.md` built from the trial reports, plus the final roadmap status update.
- **Out:** running new trials.

## Requirements

- **S12-R1 (MUST)** For each study (A, C, D, and the R4 market trial), the report states the question, arms, windows, game versions, sample sizes, primary result with interval, the `decide()` outcome, and costs.
- **S12-R2 (MUST)** It lists where automation helped, where it failed, and where it cost more than manual play, citing journal-derived figures, never anecdotes.
- **S12-R3 (MUST)** It carries forward every limitation from the trial reports and from [known-limitations.md](../baseline/known-limitations.md) that affects a conclusion.
- **S12-R4 (MUST)** Any study that did not reach its minimum sample is reported as inconclusive, not omitted.
- **S12-R5 (MUST)** The roadmap's implementation status is updated to show each release's exit evidence or what is still missing.
- **S12-R6 (SHOULD)** The figures are regenerated by `scripts/trial_report.py --study` from the committed trial data, so the report is reproducible.

## Interfaces

`scripts/trial_report.py --study` aggregates the per-trial outputs.

## Safety invariants

Reads committed reports and data only; no game access.
